## 作り方
- `bg/`: ChatGPT(gpt-image-2)で作った背景・額縁・金の飾り・光だけ。人物・建物・紋章・文字は描かせていない(`gen_bg.py` の指示文)。
- `cut/`: 宮内庁の写真の切り抜き。Canva の背景除去の結果を目安に、元の写真の輪郭に合わせて透明部分だけを計算(`cutout.py`)。お顔・お姿の画素は加工していない。
- `compose.py`: 背景+切り抜き+文字を組み立てる。`python3 compose.py` で4枚を作り直せる。

## 点検
- 「」の中「あと20年で100年もの月日が」は raw/empress2025.txt と一字一句一致(機械照合済み)。
- 文字はお顔・頭に掛けていない(体には一部掛かる)。菊の御紋・赤・黒い帯・怒りマーク・矢印・作った台詞なし。A065 は不使用。
- 「願い」(A2・ショート)は原文「語り継いでいかれることを願うとともに」に基づく。
- 注意: 長尺3枚のうち A1 と B で A061 を共用(条件に合う写真が A060・A061・A062・A066 の4枚しかないため。A063・A064 は目線が書類や帽子に向いて下がっている)。ただし A1 は切り抜きの寄り、B は室内の写真で見え方は大きく違う。
