# 長尺(横型)の表紙の型（固定）【荒木指示 2026-11-24・制作ルール第5-2章】

1280×720。**毎回この型で作り、3パターン(A/B/C)で変えるのは「写真」と「文字」だけ。** 型そのものは変えない。

## 参考にした競合の型（2026-11-24 調査・docs/research/2026-11-24_long_thumb_competitors.jpg）
それいけ皇室・みんなの皇室・皇室栄華の長尺の表紙は、3つとも次の「3段の型」をほぼ毎回くり返している。
- 上段: 画面幅いっぱいの大きな一言（かぎかっこの発言風）。極太の文字・太い縁取り
- 中段: 左に発言者の顔の大写し → 矢印 → 右に皇族方の場面写真（2〜3枚を並べる）
- 下段: 画面幅いっぱいの2行の説明文（1行目と2行目で色を変える）

**当チャンネルが取り入れるのは、この「3段の型・文字の大きさ・写真の並べ方」だけ。** 競合の表紙は、作られた発言（「」の捏造）、表情への絵文字（汗・怒りマーク・?!）、赤丸・赤文字、皇族方の対立や揶揄が中心で、これは当チャンネルの決まり（第1-2章の揶揄・対立NG、第1-5章の事実に沿う表現、第5章の赤禁止、AIや加工で人物の表情を変えない）に反するため**一切使わない**。文言・デザイン・ロゴもそのまま写さない。

## 当チャンネルの長尺の型【2026-11-24 第3版・荒木さん提供の参考画像に合わせて確定】
作成の道具: `pipeline/thumb_long.py`（型R・型D）。1280×720。

**共通**
- 書体: **明朝の極太（Noto Serif CJK JP Black）**。白文字は濃紺の縁取り＋ぼかした影。強調の一言は**金のグラデーション文字**。帯は**金のグラデーションの帯に濃紺の文字**
- **人物は1〜2名（多くても3名）**を大きく。人物を詰め込まない（ガチャガチャさせない）
- **文字はワンフレーズで短く**（1行あたり目安8〜10字。長い文は載せない）。表紙の文字はタイトルの言葉から取る
- 背景は写真。写真のない所は濃紺のグラデーション（写真へなじませる）
- 赤・絵文字・汗マーク・?!・赤丸・作り台詞の吹き出し・矢印は使わない。写真は切り抜き・拡大縮小のみ（顔の加工・AI生成はしない。参考画像の生成画像そのものは使わない）
- **お顔を文字に重ねない・見切れさせない（荒木指示 2026-11-24）：** お顔は決まった位置に決まった大きさで置く（型R: 右側 x約860・顔の高さ約240px・y約330／型D: 左右それぞれの中央・顔の高さ約175px・y約305）。髪から顎までの頭の範囲が、文字・帯の枠と重ならず、画面の外に出ないことを `check_faces` で必ず確かめる（不合格なら写真か位置を変える）。写真が足りない所は同じ写真のぼかしで埋める。主役以外の方のお顔が文字の下に半分隠れる写真は使わない
- 右下に小さく写真の出典・撮影日。**クレジットはタイトルの文字・金の帯と重ねない**（荒木指示 2026-11-24。型Dでは金の帯を y約626〜694 に上げ、その下の細い余白に置く。`credit` 関数が重なりを検査し、重なれば止める）

**写真と文字のバランス（荒木指示 2026-11-24 確定）：** **写真 約5.5割・文字 約4.5割。見る人はスマホで55歳以上の女性**と考え、文字は大きく太く（縁取り8〜9px＋影）、お顔ははっきり見える大きさ（型Rで約240px・型Dで約175px）にする。**下部に濃紺のグラデーションは敷かない**（下の文字は写真の上に縁取りで載せ、帯は金の帯だけ）。
- **主役の写真は長辺1000px以上のものを使う**（宮内庁の400px程度の写真は大きく引き伸ばすとぼやけるため、主役には使わない）
- 型は荒木さんとのやり取りで仕上げている途中。決まった点はこの文書に書き足していく

**型R（人物1名）**: 右約5.5割に人物の写真、左約4.5割に「大きな一言（白または金・約150px）」→「金の帯（約84px）」→「一言（白・約96px）」
**型D（人物2名・または人物＋場所）**: 左右に写真、上の帯に白文字（約80px）、下に**金の一言（約140px）**と金の帯（約62px）。下部に濃紺のグラデーションは敷かない。中央（お顔の高さ）には文字を置かない
  - **2026-11-25 補足（制作ルール5-3の5「文字は2か所・約20字」との両立）：** 上の帯と下の金の一言で2か所になるときは、金の帯を省いてよい（3か所目の文字にしない）。帯の代わりの小さい文字は出典（「令和3年のご感想より」など）に限り、文字の数に入れない。説明の文は入れない

## 3パターン(A/B/C)の作り分け
- タイトル3案（切り口がまったく違う: 強い疑問型／数字・事実型／人物の物語型）それぞれに表紙を1枚
- 各表紙の写真は、そのタイトルが語っている人物・瞬間・物が写っているものを選ぶ（第4-3章）。3枚で同じ写真を使わない
- 上段の引用・下段の文字も、各タイトルの言葉から取る（タイトルに無い言葉を足さない）
- 3パターンで型R・型Dを混ぜてよい（型の中身は変えない）
- 書き出し: thumb/thumb_A.png・thumb_B.png・thumb_C.png（1280×720）
