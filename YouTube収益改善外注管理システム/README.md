# YouTube収益改善外注管理システム

YouTube動画ごとの収益性・外注費・制作進捗・品質・権利リスクを一元管理し、次に改善すべきポイントを自動で判断できる実務用ツールです。

## 主な機能

- **動画管理**: 長尺・Shorts動画の登録、費用、YouTube数値、品質管理
- **外注者管理**: 外注者の単価、品質評価、納期遵守率、費用対効果
- **自動計算**: 利益、ROI、回収率、動画総合評価（100点満点）、修正負担スコア
- **ダッシュボード**: 月別収支、制作進捗、警告、上位/赤字動画
- **収益分析**: 月別推移グラフ、長尺vsShorts比較、費用内訳
- **制作進捗管理**: ステータス別表示、納期遅延ハイライト
- **権利リスク管理**: AI生成画像、転載、再利用コンテンツ等のリスクチェック
- **月次レポート**: 投稿本数、収支、外注者評価、改善提案の自動生成
- **CSV入出力**: 動画・外注者データのインポート/エクスポート
- **警告機能**: 納期超過、未払い、修正過多、権利リスク等の自動警告

## 技術スタック

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS
- SQLite + Prisma ORM
- Recharts（グラフ）
- React Hook Form + Zod（フォーム・バリデーション）

## セットアップ

### 前提条件

- Node.js 18以上

### インストール

```bash
cd YouTube収益改善外注管理システム
npm install
```

### データベース初期化

```bash
npx prisma migrate dev
```

### 開発サーバー起動

```bash
npm run dev
```

ブラウザで http://localhost:3000 を開いてください。

### サンプルデータ投入

設定画面（http://localhost:3000/settings）から「サンプルデータを投入」ボタンを押すか、以下のコマンドを実行してください。

```bash
curl -X POST http://localhost:3000/api/seed
```

## 画面構成

| 画面 | パス | 説明 |
|---|---|---|
| ダッシュボード | `/` | 月次サマリー、警告、利益上位/赤字動画 |
| 動画一覧 | `/videos` | 検索・フィルター付き動画リスト |
| 動画詳細 | `/videos/[id]` | 全情報表示、分析、警告 |
| 動画登録・編集 | `/videos/new` | 基本情報・費用の入力 |
| 外注者一覧 | `/outsourcers` | 外注者リスト、評価表示 |
| 外注者詳細 | `/outsourcers/[id]` | 詳細情報、担当動画 |
| 外注者登録・編集 | `/outsourcers/new` | 外注者情報の入力 |
| 制作進捗 | `/progress` | ステータス別進捗管理 |
| 収益分析 | `/analytics` | グラフによる収益・費用分析 |
| 権利リスク | `/risks` | リスクフラグ付き動画一覧 |
| 月次レポート | `/reports` | 月別レポート生成 |
| CSV入出力 | `/csv` | データのインポート/エクスポート |
| 設定 | `/settings` | チャンネル設定、サンプルデータ |
