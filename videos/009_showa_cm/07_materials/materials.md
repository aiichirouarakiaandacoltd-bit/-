## 重要注意事項
**このテーマは著作権リスクが特に高い。以下を厳守すること：**
- 実際のCM映像は一切使用しない
- 実際のCM音楽・ジングルは一切使用しない
- 特定タレントの実写写真は使用しない
- 企業ロゴ・商品のビジュアルは使用しない

## 使用禁止素材

| 種類 | 理由 |
|------|------|
| 実際のCM映像クリップ | 著作権（放送局・制作会社・出演者） |
| CMジングル・BGM | 著作権（音楽著作権・隣接権） |
| タレントの実写写真 | 肖像権・パブリシティ権 |
| 企業ロゴ・商品画像 | 商標権・著作権 |
| 昭和の雑誌・広告スキャン | 著作権（50年経過していない可能性） |
| テレビ番組のキャプチャ | 著作権（放送局） |

## 代替表現の工夫

| 使いたいもの | 代替手段 |
|-----------|---------|
| 実際のCMフレーズ | 「○○という言葉で始まるCMがありました」と言葉で説明 |
| CMの映像 | AI再現画像で「昭和のテレビCMのイメージ」を表現 |
| 特定タレント | 「当時人気だった俳優が出演したCM」という表現 |
| CMソング | 「歌のような形式のCM（ジングル）」という説明 |
| 特定企業のCM | 「ある食品メーカーのCMで……」という形 |
