# 固定コメント案：なぜ商店街は消えたのか

---

## パターン1：視聴者への質問型（推奨）

```
あなたの子ども時代、よく行った商店街はありましたか？
魚屋さん・八百屋さん・肉屋さんの記憶を、ぜひコメントで教えてください😊
「ツケ払い」の文化を覚えている方もぜひ。
```

---

## パターン2：補足情報型

```
動画内でご紹介した「約17,000ヶ所」という数字は中小企業庁の調査に基づく概数です。また大店法廃止が商店街衰退の「唯一の原因」ではなく、複合的な要因の一つです。
現在も全国各地でがんばっている商店街があります。ぜひ地元の商店街を覗いてみてください🏪
```

---

```
「消えた日本」シリーズ第2弾です。
第1弾「なぜ駄菓子屋は消えたのか」もあわせてご覧ください。
```

## 推奨：パターン1と2の組み合わせ

```
あなたの子ども時代、よく行った商店街はありましたか？
```
