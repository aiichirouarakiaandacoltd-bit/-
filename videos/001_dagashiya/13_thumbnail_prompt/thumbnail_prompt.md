# サムネイル生成プロンプト：なぜ駄菓子屋は消えたのか

**推奨サイズ**：1280×720px（16:9）  
**形式**：JPG または PNG

---

## パターン1：ノスタルジック写真風（推奨A）

**テキスト構成**：
- メイン：「なぜ消えたのか」（大きく、白文字）
- サブ：「全国15万軒の駄菓子屋」（小さく、黄色）
- 右下：チャンネルロゴ

**Midjourneyプロンプト（背景画像生成用）:**
```
Interior of a nostalgic Japanese dagashiya candy shop from the 1970s, warm amber lighting, glass display case with colorful candies, wooden shelves, slightly dark and atmospheric, sepia-toned memory feel, wide angle, no text, photorealistic --ar 16:9 --v 6 --style raw
```

**Canvaでの仕上げ指示:**
- 背景：上記AI生成画像（または実物写真）
- 全体に薄いセピア/アンバーオーバーレイ（透明度30〜40%）
- メインテキスト「なぜ消えたのか」：白・太字・大きめ・左寄せ・縁取り（黒1px）
- サブテキスト「全国15万軒の駄菓子屋」：黄（#FFD700）・細字・メインの下
- 左下に「再現イメージ」（AI画像使用時のみ、小さく）

## パターン3：令和×昭和コントラスト型

**テキスト構成**：
- 左半分（昭和）：「あの頃」+ 駄菓子屋の画像（セピア）
- 右半分（令和）：「今は？」+ コンビニの画像（カラー）
- 中央：「駄菓子屋が消えた理由」（大きく）

**Canvaでの構成指示:**
- 画面を左右に分割するデザイン
- 左（昭和）：AI生成の駄菓子屋画像、セピアフィルター
- 右（令和）：実物撮影のコンビニ画像、カラー
- 中央に縦の境界線（白）
- 「昭和」「令和」の小ラベル（各側の上部）
