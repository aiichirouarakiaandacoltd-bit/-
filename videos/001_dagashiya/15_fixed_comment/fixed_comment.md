# 固定コメント案：なぜ駄菓子屋は消えたのか

---

## パターン1：視聴者への質問型（推奨）

```
あなたが子どもの頃に通っていた駄菓子屋を覚えていますか？
どんなお菓子をよく買っていましたか？
ぜひコメントで教えてください😊
```

*→ 視聴者参加を促す。コメント欄が思い出話で盛り上がる可能性大*

---

## パターン2：補足情報型

```
動画内でご紹介した「全国約15万軒」という数字は、業界推計値であり正確な統計データは存在しません。
また、現在も全国で営業を続けている駄菓子屋さんがあります。あなたの街に残っていたら、ぜひ一度立ち寄ってみてください🏪
```

*→ 正確性へのコミットメントを示す。誤解防止にも有効*

---

## パターン3：シリーズ誘導型

```
「消えた日本」シリーズでは、駄菓子屋のほかにも昭和平成に存在した風景・文化をお届けします。

```

*→ シリーズとしての視聴継続を促す*

## 推奨：パターン1と2の組み合わせ

```
あなたが子どもの頃に通っていた駄菓子屋を覚えていますか？
どんなお菓子をよく買っていましたか？ぜひコメントで教えてください😊

なお、動画内の「約15万軒」という数字は業界推計値です。
現在も営業中の駄菓子屋さんが全国にあります。
あなたの街に残っていたら、ぜひ立ち寄ってみてください。
```

## 固定コメント設定のタイミング
- 動画投稿直後に設定
- 投稿から24時間以内を目安に

## 固定コメントの効果
- コメント欄の雰囲気を「懐かしい思い出話」の場にする
- 最初に表示されることで、他の視聴者のコメントのトーンを誘導
- チャンネルの姿勢（正確性・温かさ）を示す
