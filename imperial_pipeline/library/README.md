# library/ — 安全素材ライブラリ

## 位置づけ（第0章 0-4 の方針転換）

本システムは「使えそうな素材を探して権利を判定する」設計を採らない。
**使用可能と確認済みの素材を先に登録し、その範囲内で台本と画面を設計する**。

`approved_materials.csv` は、荒木愛一朗が利用条件を確認し、
このチャンネルで使用してよいと判断した素材だけを登録する台帳である。
システムが自動で行を追加することはない。**登録は人手で行う。**

## 列の意味

| 列 | 記入内容 |
| --- | --- |
| 素材ID | `L001` から連番。プロジェクト内の素材ID（`M001`）とは別体系。 |
| 素材名 | 編集者が識別できる名称。 |
| 種別 | 公式写真／公式動画／公的資料／図解／地図／建物・会場／一般イメージ／音源 など。 |
| 権利者 | 著作権者・提供元。不明な素材は登録しない。 |
| 取得元URL | 素材の掲載ページ。 |
| 利用条件 | 出典元が明記している条件を、要約せずそのまま書き写す。 |
| YouTube利用可否 | 使用可／条件付き使用可／使用非推奨／使用禁止／要確認 |
| クレジット条件 | 概要欄または画面に必要な表記。不要なら「不要」と明記する。 |
| 加工可否 | トリミング可否、色調補正可否、文字重ね可否などを具体的に書く。 |
| 有効期限 | 期限付きライセンスの場合に記入。無期限なら「無期限」。 |
| 登録日 | YYYY-MM-DD |
| 確認者 | 利用条件を確認した人物名（原則「荒木愛一朗」）。 |
| 備考 | 注意点、使用してはいけない文脈など。 |

## 登録してはならない素材

- 権利者が特定できない写真・映像
- 出典が不明な人物写真
- SNS投稿画像
- 報道機関の写真・映像（原則「使用非推奨」。個別に許諾を得た場合のみ、
  許諾内容を利用条件欄へ全文記載したうえで登録する）
- 皇族方のAI生成顔、顔の合成・変形・若返り・老化を含む素材
- 「公式サイトに載っているから」という理由だけで可と判断した素材

## 素材が不足する場合

無理に素材を探さず、素材設計側で **「素材不足」** と明記し、
次の代替手段へ切り替える。

1. 自社作成の図解（年表、関係図、制度図）
2. テロップ中心画面
3. 地図
4. 建物・会場の外観（利用条件を確認済みのもの）
5. 一般イメージ（画面上に「イメージ」と明示すること）
