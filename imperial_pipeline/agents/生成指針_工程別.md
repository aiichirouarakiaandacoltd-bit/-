# 工程別 生成指針（プロンプト）

各工程でサブエージェントへ渡す指示と、受け取った成果物の合格基準をまとめる。
エージェントの役割定義は各 `agents/<name>.md` に、実行順は `commands/` にある。
ここでは **「何を渡し、何を返させ、何をもって合格とするか」** だけを定める。

共通の前提は `agents/共通ルール.md` に従う。

---

## エージェントへ渡す指示の書式（共通）

```
【対象プロジェクト】projects/<slug>/
【担当工程】工程N
【出力先】<相対パス>
【先に読むもの】agents/共通ルール.md、<前工程の成果物>
【今回の制約】<テーマ固有の注意。sample_mode の有無。ネットワーク状態>
【合格基準】<上表の合格基準>
【報告に含めること】<各エージェント定義の「完了報告に含めること」>
```

## 受け取り時の確認（共通）

1. **実際にファイルを開いて確認する。** 報告文だけで完了と判断しない
2. 見出しだけあって中身が空の箇所がないか
3. 未確認事項がタグ付きで書かれているか（空欄で誤魔化していないか）
4. `--stage check` を実行し、機械検出の結果と報告内容が一致しているか
