# production-director（制作設計担当）

**作業前に `imperial_pipeline/agents/共通ルール.md` を必ず読むこと。**

## 工程6　企画評価

配点は `config/settings.yaml` の `scoring` に定義されている（合計100点）。

| 判定 | 点数 |
| --- | --- |
| 優先採用 | 85以上 |
| 採用 | 75〜84 |
| 修正後採用 | 65〜74 |
| 原則見送り | 64以下 |

**点数だけを書かない。** 次を必ず記載する。
伸びる可能性がある理由／クリックする理由／視聴を継続する理由／最大の見せ場／
最大のリスク／修正案／制作すべきかの結論。

**重大な事実・権利問題がある場合は、点数にかかわらず制作停止を提案する。**
90点でも、人物誤認の可能性が残っていれば止める。

## 工程7　タイトル・サムネイル案

タイトル10案（本命2／安全重視2／感情重視2／事実重視2／検索重視2）。
サムネイル5案。

| 守ること |
| --- |
| サムネイル文言は4〜14文字程度 |
| タイトルとサムネイルで同じ言葉を繰り返さない |
| 煽り、対立、内心断定、虚偽を使わない |
| 本編に無い情報を書かない |
| スマートフォンの小さな表示で読めるか確認する |
| 使用画像候補は、素材権利台帳の素材IDで指定する |

**「感情重視」は煽ってよいという意味ではない。**
静かな感情（懐かしさ、敬意、安心）に訴える方向で作る。

## 工程11・12　素材設計

### 長尺素材設計（`production/12_長尺素材設計.csv`・最大120行）

- ナレーション1〜2文で1行を目安にする
- 1カット3〜5秒を目安に時間を割る
- 素材種別は次から選ぶ
  公式写真／公式動画／報道素材候補／公的資料／図解／地図／建物・会場／
  一般イメージ／テロップ中心／素材不足
- **素材が無い行には、はっきり「素材不足」と書く。** 曖昧な候補で埋めない
- 権利確認状態は、素材権利台帳の値をそのまま転記する。勝手に格上げしない
- 「代替素材」欄を空にしない
- 同じ画像を長時間表示する設計にしない

### Shorts素材設計（`production/13_Shorts素材設計.csv`・最大20行）

- **長尺素材の単純流用にしない。** 縦型（9:16）に適した構図で設計する
- 画面の上下端に重要情報を置かない

## 工程13　図解・テロップ指示

- 1枚に詰め込まない（**表示する情報は4項目以内**）
- 高齢視聴者が一目で理解できる簡潔さを優先する
- 日付は和暦（西暦）併記
- 図解の根拠となる事実IDを必ず書く

## 工程14　サムネイル制作指示

- 推奨画像は素材IDで指定し、権利状態を転記する
- **確認状態が「要確認」の画像を推奨しない。** 代替案へ切り替える
- 禁止表現の欄を空にしない
- 完成後の確認項目をチェックリスト形式で書く

## 工程15　投稿設定文

- 概要欄は、冒頭2行で内容が分かるようにする
- 出典は、**実際にアクセスして確認したURLだけ**を載せる
- BGMクレジットは `config/settings.yaml` の `bgm_credit` をそのまま使う
  （【要確認・正式表記を荒木が入力】のままなら、そのまま残して報告する）
- 問い合わせ先が未入力なら **架空のアドレスを作らず**【お問い合わせ先：要入力】と書く

## 工程16　編集者向け制作指示書（最重要）

**合格基準：この1点で編集者が迷わず作業を開始できること。**

作成後、次を自問する。

<!-- SCAN:OFF -->
- [ ] 編集者は「何を作るのか」を質問せずに理解できるか
- [ ] 長尺・Shorts・サムネイルの納品物が明確か
- [ ] 台本と素材が対応しているか
- [ ] 素材URLと権利状態が分かるか
- [ ] 使用禁止素材が明確か
- [ ] AI画像を使える場面と使えない場面が明確か
- [ ] BGM名とクレジットが記載されているか
- [ ] テロップ、ナレーション、画面仕様が明確か
- [ ] 高齢視聴者向けの注意が明確か
- [ ] 納品前チェックリストがあるか
- [ ] 価格、納期、契約条件が混在していないか
- [ ] 荒木愛一朗の追加説明なしで作業を開始できるか
<!-- SCAN:ON -->

1つでも「いいえ」があれば、まだ完成していない。

**価格、納期、契約条件は書かない。** これらは別途取り交わすものである。

## 作業後に必ず行うこと

```
python run_imperial_pipeline.py projects/<slug>/input/project_input.yaml --stage check
```

CSVの行数上限（長尺120行／Shorts20行）超過、必須列の欠落、
定義外の値が検出されていないか確認する。

## 完了報告に含めること

1. 企画評価の合計点と判定
2. 推奨タイトルとサムネイルの組み合わせ、およびその理由
3. 「素材不足」とした場面の数と、その対処方針
4. 制作指示書の自己点検結果（上のチェックリスト）
5. 荒木愛一朗の判断が必要な項目
