# YouTube制作指示書 生成

外注編集者が**これ一本を見れば完成まで到達できる**指示書を作る。
チャンネル共通設定（ナレーター、BGM、権利、視聴者、納品形式）はリポジトリ直下の `CLAUDE.md` にある。先に読むこと。

---

## 最初に確認する

### 入力

必要なのは2つだけ。

1. **正式タイトル**
2. **長尺の想定尺**（例：15分〜17分）

**タイトルが空欄・未指定のまま進めない。** これは唯一の例外的な確認ポイント。
テーマが違えば成果物は丸ごと無駄になるので、推測で埋めるより一度聞いたほうが速い。
過去資料からテーマを推測して作り始めるのは失敗パターン。資料に出てくるテーマは、見本や過去回であることが多い。

想定尺が未指定なら、テーマ資料の指定に従う。それも無ければ15分〜17分を既定として明記して進む。

### 資料

`CLAUDE.md` → Google ドライブの順で確認する。

* 今回のテーマの資料（`search_files` で `fullText contains '〔テーマ語〕'`）
* 直近の完成版制作指示書（`fullText contains '制作指示書'`）
* チャンネル企画書・視聴者設定・BGM・素材ルール

**複数の資料で内容が違う場合は、更新日時が新しいものを優先する。**
食い違いを見つけたら、どちらを採ったかを成果物の「出典・参考資料」へ記録する。編集者が混乱しないように。

情報が足りなくても質問で止まらない。確認できた範囲で最大限作り、不明部分は **【要確認】**、URLは **【URL未取得】** と書く。

### 見本の扱い

`references/見本_第4本目_ラジオ体操.md` は**到達水準を示す完成例**。

真似るのは**粒度と具体性**であって、中身ではない。
章立て、シーン割り、ナレーション、図解の内容を別テーマへ流用しない。テーマが変われば問いも笑いどころも図解も別物になる。

## 品質を決める5原則

ここが「レベル感」の正体。ここを外すと、形式だけ整った使えない指示書になる。

### 原則1　記憶から入る。説明から入らない

冒頭で歴史や一般論を始めない。**視聴者の体が覚えているもの**から入る。
物、音、時刻、手触り。「自分もやった」と思わせてから、初めて問いを立てる。

見本の冒頭8秒は、目覚まし時計 → 布団から伸びる手 → 首から下げるカード → サンダル → 赤いハンコ。
歴史（1925年、アメリカ、逓信省）が出てくるのは4分後。この順序が動画の生死を分ける。

チャンネルロゴやオープニングアニメーションから始めない。1秒目から本編。

### 原則2　画面設計に「何を映すか」を書く

**これが指示書の価値のほぼすべて。**
「適切な素材を表示」「イメージ映像」で終わらせた行は、書いていないのと同じ。

各シーンで次を書く。

* 何を映すか（①②③…と順番に）
* どこを大きく見せるか
* どの順に出すか
* どの音で次へつなぐか

**悪い例**：昭和の子どもの様子を表示
**良い例**：①早朝の住宅街の引き、人けがない ②公園へ集まる子どもたち ③前に立つ大人がラジオのスイッチを入れる手元をアップ ④全体が動き出すが、そろっていない ⑤腕が上がっていない子を正面から

さらに、**撮り方の統一で意味を作る**指定を入れられると水準が上がる。
「②③④は同じ位置・同じ画角で撮り、年代だけが変わることを見せる」
「①②と③④⑤を同じ部屋・同じ画角で撮り、生活が変わることを見せる」

つなぎも具体的に。「自転車から、昭和初期の古い自転車と町並みへマッチカット（形とスピードを合わせる）」「朝日のオレンジから、次章の赤いハンコへ色をつなぐ」。

### 原則3　時間は連続させ、合計を一致させる

章は6〜8章。**章の終了時刻＝次の章の開始時刻**。空白も重複も作らない。
シーン単位でも同じ。シーンの時刻を積み上げた合計が、章の尺と一致すること。

最後に終了画面用の余白を5〜10秒。
**冒頭60秒はカット単位（秒数付き）で設計する。** 離脱が最も起きる区間だから、ここだけ粒度を上げる。

画面変化の目安：冒頭30〜40秒＝2〜4秒／生活描写＝3〜6秒／歴史説明＝5〜8秒／図解＝6〜10秒／感情回収＝5〜9秒。
これは目安。秒数を機械的に守るより、ナレーションの区切り、視聴者の理解、感情の流れを優先する。

### 原則4　事実は留保付きで、誤解は構造で防ぐ

創作しない。これは `CLAUDE.md` の共通ルール。

そのうえで、**誤解は文言だけでなく図解の構造で防ぐ。**
条件の違う2つの数字を並べるとき、間に矢印を置けば、視聴者は勝手に因果を読む。だから「矢印を入れない」「中央は空白のまま」「増加グラフにしない」を**図解の禁止表現として明文化する。**

見本の図解3がこの型：左「1930年 約130人」／右「1932年 延べ2,593万人」／中央に何も置かない／下部に赤字で「そのまま全国へ広がった、という記録があるわけではありません」を最初から最後まで表示。

「事実・表現上の注意」は必ず**「正しい扱い」と「禁止表現」をセット**で書く。禁止だけ並べても、編集者は何をすればいいか分からない。

### 原則5　音で感情を作る

BGMを「全編で流す」で終わらせない。**どこで下げ、どこで止め、どこで戻すか**を時刻付きで指定する。

最も効くのは**止めてから戻す**設計。
見本では、終戦の日にBGMを完全停止し、日付を無音で8枚流し、8日後のラジオのスイッチ音で再開する。文章では作れない感情がここで生まれる。

効果音は「使用可」と「禁止」を列挙し、**回数の上限**も書く（コミカル音は2〜3か所まで、など）。効果音はナレーションより前に出さない。

## 作業手順

1. **中心となる問いを1文で決める。** タイトルの問いを、視聴者の記憶のどこから入って解くか。ここが決まらないと章立ては決まらない
2. **視聴前の認識 → 視聴後の認識**を1行ずつ書く。この差分が動画の価値
3. **章立てと時間配分**を決める（6〜8章）。連続性を確認
4. **各章のシーン**を割り、時刻を積む。冒頭60秒はカット単位で
5. **ナレーション全文**を書く。各章末に、1文ずつ改行、VOICEVOXへそのまま貼れる状態で
6. **画面設計**を原則2の粒度で埋める
7. **図解を4〜7個**設計。テーマ／目的／画面構成／表示順／注記／禁止表現
8. **音、字幕、サムネイル、Shorts、素材・AI再現、事実注意**を設計
9. **チェックリストと最終合格基準**を書く。今回の動画固有の人物・数字・結論を含める

出力する節の並びと見出しは `references/テンプレート.md` に従う。
各節で守る具体的な水準（良い例／悪い例の対比）は `references/品質基準.md` を読む。

## 出力方法

**Markdownファイルとして書き出す。ターミナルへ全文表示しない。**

出力先の指定が無ければ、リポジトリ直下に `〔連番〕本目_〔テーマ略称〕_制作指示書.md` で保存する。

1回の出力に収まらないので、次の順で分割して書き、**要約・省略せず最後まで書き切る。**
各回の書き出し後、確認を求めずに自動的に次へ進む。

1. 冒頭〜音声・BGM設計
2. 章別制作設計（ナレーション全文を含む）
3. 図解〜最終合格基準
4. 出典・参考資料、未確定事項

分割して書くときは、パートごとに別ファイルへ書いてから `cat` で結合すると、追記の失敗や重複が起きない。

## 出力前の自己検証

書き終えたら、次を実際に確認してから報告する。目視で「たぶん大丈夫」で済ませない。

* 章とシーンの時刻を足し上げ、**合計が想定尺と一致**しているか。空白・重複がないか
* **ナレーション全文が全章にあるか**（見出しを機械的に数える）
* シーン表の「画面設計」に「適切な素材」「イメージ映像」で終わっている行がないか
* 人物名・日付・数字・URLを創作していないか。不明箇所が【要確認】【URL未取得】になっているか
* 支給素材が【発注者支給】【編集者制作】【支給有無 要確認】のいずれかで区分されているか
* 図解ごとに「禁止表現」が書かれているか
* 内部検討の内容（迷った経緯、候補の比較）が外注者向け文書に混ざっていないか
* 見本のテーマ固有の内容が紛れ込んでいないか

**重大な不足が残る場合は「完全版」と表記せず【暫定版】とし、末尾に「未確定・要確認事項」を一覧化する。** 着手前に確定が必要なものと、納品前までに確定すればよいものを分けて書くと、編集者が動き出せる。

完成した制作指示書だけを出力する。作業過程や前置きをファイルへ書かない。
