## 1．この動画の設計方針

### 中心となる問い

**夏休みは学校へ行かなくてよい期間なのに、なぜ多くの地域で、決まった朝に集まって体操をしていたのか。ハンコと最後の景品のためだけだったのか。**

この問いは、視聴者の記憶から入って解き明かします。
**冒頭から歴史説明や一般論を始めないでください。** 1925年もアメリカも逓信省も、視聴者が「自分もやった」と思い出したあとで出します。

### 視聴前の認識 → 視聴後の認識

| | 内容 |
| -- | -- |
| 視聴前 | ラジオ体操は、ハンコや景品をもらうために行っていた夏休みの習慣 |
| 視聴後 | 生活リズム、健康づくり、ラジオ放送、継続を見える形にするカード、地域の見守り。複数の役割が重なっていた。現在のラジオ体操第一は3代目であり、御大礼記念の事業、放送、地域活動、全国巡回などの歴史が重なって、あの朝の風景ができた |

### 視聴後に残す感情

* 面倒だったけれど、悪い思い出ではない
* 赤いハンコの向こう側に、地域の大人たちの思いがあった
* 自分の地域の景品を話したい

### 全体の流れ

1. 冒頭の記憶・違和感（夏休みなのに学校より早起き）
2. 視聴者が知っている日常（眠い朝、カード、公園、適当な体操）
3. タイトルの問いを立てる（なぜ毎朝だった？）
4. 意外な背景・歴史の発見（御大礼記念事業／一人の巡査と町内会／3代目）
5. タイトルへの答え（5つの役割）
6. 現在との違い（令和の多様な開催の形）
7. 視聴者自身の記憶へ戻す（赤いハンコに残っていたもの）
8. コメントしたくなる質問一つ（最終日の景品）
9. 終了画面

### 笑いの方向

**「分かる、そうだった」と思える笑いにします。人を小馬鹿にする笑いは使いません。**

* 笑いの対象は「当時の自分たち全員」であって、特定の誰かではありません
* 上級生、犬の散歩の人、遅刻する子を「ダメな人」として描かないでください。全員が同じ眠さの中にいた仲間として描きます
* 効果音でのオチ付けは1シーンにつき1回まで。連発すると教養バラエティの品が落ちます

使用は編集者の裁量です。**全部を使う必要はありません。第1章・第2章に集中させ、第3章以降は原則使いません**（歴史パートに入れると軽くなります）。1画面1本、表示1.2〜2.0秒、通常字幕より小さめ、画面の隅に置いてください。

# 7．図解設計

図解は文章を飾るためではありません。**時系列・数字・世代交代・複数の理由を、一目で理解させる場面に限定して使用します。**

## 図解 共通ルール

* 要素を一度に全部出さず、**ナレーションに合わせて順に出す**
* **図解だけを長時間静止させない。** 8秒を超える場合は、途中に実写やAI再現を1〜2カット挟んで図解へ戻る
* **条件の違う数字を、増加グラフや矢印で結ばない**
* **後の章で見せる結論を、図解で先に出さない**
* 文字を四角で囲んで矢印でつないだだけの構成は避ける。**図形の配置そのものが情報の関係を表すように設計する**（時間は横一直線、複数要素の並立は中心からの放射、対比は左右対称）
* 高齢視聴者が中心です。1画面の要素は最大6個まで。文字を小さくしすぎない
* 全6点でデザインを統一（同じフォント、同じ配色、同じ角丸、同じ余白）
* 配色は、昭和・平成側＝オレンジ〜黄土、令和・現在側＝水色、強調＝赤、地＝生成りの白。**赤は注意書きと1か所の強調にだけ使う**

# 8．サムネイル設計

## 目的

歴史を説明するのではなく、**「なぜ、あんなにハンコが欲しかったのか」という記憶と疑問を一瞬で呼び起こす。**

## 画面構成

| 位置 | 内容 |
| -- | -- |
| 左 | 眠そうな昭和の小学生。首から下げた自作の出席カード。早朝の公園へ歩く姿。**大げさな驚き顔にしない。眠い、が正解** |
| 右 | 赤いハンコを押す手。ハンコが並んだ自作カード。**赤い丸を大きく見せる** |
| 背景 | 青空、夏の緑、朝日、公園。**セピア一色にしない。**夏の朝の明るさを残す |

## 最優先要素

**赤いハンコ。** 小さく表示されたときに、最初に目に入るのはこの赤でなければなりません。

## 文字

| 区分 | 文言 | 仕様 |
| -- | -- | -- |
| メイン | **ハンコのためだけ？** | 最大文字。2行以内。黄または白＋黒縁 |
| 補助 | 夏休みの朝6時半 | メインより小さく。白またはオレンジ。1行 |

主要要素は **①赤いハンコ ②眠そうな子ども ③メイン文字 ④補助文字** の4個以内。これ以上増やさないでください。

## 視認順

**赤いハンコ → 眠そうな子ども → メイン文言「ハンコのためだけ？」 → 補助文言「夏休みの朝6時半」**

この順に目が動くよう、明度差とサイズ差を設計してください。

## タイトルとの関係

正式タイトルは「なぜ夏休みになると、毎朝ラジオ体操へ行っていたのか」です。
サムネイルはこれを繰り返さず、**「ハンコのためだけ？」＋「夏休みの朝6時半」で、タイトルと組み合わせて一つの疑問を作ります。**
サムネイルだけを見たとき「ハンコ以外に何があったの？」と思わせるのが成功です。

## 禁止事項

* **正式タイトル全文を入れる**
* 公式出席カード、NHKロゴ、公式ロゴ・公式キャラクター
* 極端な驚き顔、泣き顔
* 全体を暗いセピアにすること
* 情報の詰め込み（要素5個以上、文字25字以上）
* 赤い矢印・囲みの乱用
* 実在人物の写真、AI生成した実在人物の顔

## 確認

**スマートフォンの一覧表示サイズ（幅約320px相当）に縮小して確認してください。**
その状態で「赤いハンコ」と「ハンコのためだけ？」が読めなければ、要素を減らすか文字を大きくしてください。

# 13．最終合格基準

## 視聴者の感情が動く順序

**懐かしい → 自分も適当に体操していた → ハンコの時だけ元気だった → でも、なぜ毎朝だったのか → 御即位記念の事業だったのか → 今の第一は3代目だったのか → ハンコのためだけではなかった → 自分の地域では何をもらったか話したい**

この順で動けば合格です。途中で「説明されている」と感じさせたら失敗です。

## この動画が提供する体験

夏休みの朝、眠い目をこすって公園へ行き、赤いハンコを一つもらう。誰もが持っているその記憶を、笑いながら思い出すところから始まります。腕が上がらない子、虫を見ている子、毎朝いる犬の散歩の人。当時は意味など考えなかったあの朝に、実は生活のリズム、健康づくり、ラジオという仕組み、続けたことを見える形にするカード、そして地域の大人たちの目という、五つの役割が重なっていたことを知ります。さらにその始まりが、御即位の御大礼を記念する事業であり、一人の巡査と町内会の人たちの朝であり、いま体で覚えているあの動きが三代目であることを知る。見終えたとき、視聴者の記憶の中の赤い丸は、出席の印から、夏休みの朝そのものの記録へと意味を変えています。**知識を並べる動画ではなく、自分の記憶が一段深くなる動画です。**
