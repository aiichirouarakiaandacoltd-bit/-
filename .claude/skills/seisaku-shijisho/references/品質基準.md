## 1．画面設計

指示書の価値のほぼすべてがここに出る。

**悪い**
> 昭和の子どもたちの様子を表示

**悪い**
> 当時の街並みのイメージ映像

**良い**
> ①早朝の住宅街の引き、人けがない ②公園へ集まる子どもたち ③前に立つ大人がラジオのスイッチを入れる手元をアップ ④全体が動き出すが、そろっていない ⑤腕が上がっていない子を正面から

書くべき4点：**何を映すか（順番に）／どこを大きく／どの順に出すか／どの音で次へつなぐか**

### 撮り方の統一で意味を作る

同じ画角で撮って一要素だけ変える指定は、言葉で説明せずに意味を伝えられる。

> ②③④は同じ位置・同じ画角で撮り、年代だけが変わることを見せる
> ①②と③④⑤を同じ部屋・同じ画角で撮り、生活が変わることを見せる
> 5つの会場をすべて同じ画角・同じ明るさの早朝でそろえ、場所だけが変わることを見せる

### つなぎ

> 自転車で走る子どもから、昭和初期の古い自転車・町並みへマッチカット（形とスピードを合わせる）
> 朝日のオレンジから、次章の赤いハンコへ色をつなぐ
> 全国地図から、いつもの地域の公園へズームして次章へ

### 撮ってはいけない指示も書く

> 個人を嘲笑する寄りにしない。全員が同じ眠さの中にいるように撮る
> 巡査だけを中央に大きく置かず、町内会の大人と同じ大きさ・同じ高さで並べる
> 「監視」に見えない距離感で。笑顔と挨拶を中心に
> 誰もいない公園を最後に置くが、暗く撮らない。朝日の入る明るい無人の公園に

## 2．ナレーション

* **1文ずつ改行。** VOICEVOXへそのまま貼れる状態
* 一文を短く。読点で延ばさず、切る
* 体言止めを混ぜてリズムを作る（「腕が上がっていない子。」「寝癖は、そのまま。」）
* 数字・年号・重要結論の直後は、間を取れる文の切り方にする
* 断定を避ける（「〜と考えられます」「〜ではないでしょうか」「多くの地域では」）
* 視聴者へ問いかける文を、章の変わり目に置く（「では、この習慣は、どこから始まったのでしょうか。」）

**悪い**
> 1928年に国民保健体操が制定され、同年11月に東京中央放送局から朝7時の放送が始まり、1929年2月には全国放送となりました。

**良い**
> 翌1928年、昭和3年9月。
> 簡易保険局を中心に、日本放送協会や文部省などの協力を得て、「国民保健体操」という名称で、初代のラジオ体操第一が制定されます。
> 同じ年の11月、東京中央放送局から、朝7時の放送が始まりました。
> 1929年2月には、全国放送になります。

## 3．ツッコミ字幕

10個程度。**具体的であることが命。** 抽象的なものは1つも笑えない。

**悪い**：懐かしい／みんなやった／あるある
**良い**：寝癖はそのまま／体操より虫／その犬は毎朝いる／上級生も適当／腕、隣に当たってます／目は閉じたまま／なぜ朝になると消えるのか

観察の解像度がそのまま笑いの強さになる。「その犬は毎朝いる」は、記憶にあるのに誰も言語化していないから効く。

**方向**：笑いの対象は「当時の自分たち全員」。特定の誰か（父親、上級生、遅刻する子）を悪く描かない。

**使用ルールも書く**：集中させる章（前半）／歴史パートには原則入れない／1画面1本／表示1.2〜2.0秒／通常字幕より小さめ／画面の隅／全部使う必要はない

## 4．大字幕

5〜8個。**動画の骨格がここに出る。** 増やすと1つずつが弱くなる。

置く場所：問いを立てる瞬間／最大の意外性／数字の驚き／タイトルへの答え／感情の回収／最後の質問

演出も書く：
> 表示後0.5秒静止して疑問を残す
> 直前でBGMを下げ、読み終わりに0.7秒の間
> 「8」を赤で強調
> 読了後1秒の間。その1秒はBGMも下げる

## 5．図解

### 図形の配置が情報の関係を表すこと

文字を四角で囲んで矢印でつないだだけの構成は避ける。

| 情報の型 | 配置 |
| -- | -- |
| 時系列 | 横一直線。太さを均一に。分岐を作らない |
| 並立（順位なし） | 中心から放射状。すべて同じ大きさ・同じ色の重み |
| 対比 | 左右対称。同じ面積・同じ要素数・同じ文字サイズ |
| 一日の流れ | 横一直線の節。節はすべて同じ大きさの円 |

**放射状の配置そのものが「順位がない」ことを表す。** 縦の箇条書きにすると、上から順に重要だと読まれる。

### 表示順を必ず書く

> 中心の出席カードを先に表示 → 生活リズム → 健康づくり → ラジオ → 継続の記録 → 地域の見守りの順に1つずつ → 全体を見せる → 「〜」で図全体を軽く拡大

> 初代のみ表示 → 0.8秒後に2代目 → さらに0.8秒後に3代目 → 「現在の第一」で3代目を軽くズーム → 「3代目なのです」で初代・2代目の明度を下げる

### 誤解は構造で防ぐ

条件の違う2つの数字の間に矢印を置けば、視聴者は勝手に因果を読む。文言で否定しても画が勝つ。

> **左右完全分離。左右の間に矢印・線・グラフを一切置かない。中央は空白のまま。**
> 下部に赤字で「〜という記録があるわけではありません」を**最初から最後まで表示**

### 禁止表現を図解ごとに書く

> 「130人から全国へ」「わずか2年で拡大」などの字幕・ナレーション／中央の矢印／増加グラフ／左右をつなぐアニメーション
> 左右を競わせる矢印／勝敗記号／○×／優劣を示す色（片方だけ暗い、片方だけ彩度が低い）／「失われた」「消えた」などの語

### その他

* 8秒を超えるなら、途中に実写やAI再現を1〜2カット挟んで図解へ戻る
* 後の章で見せる結論を先出ししない（年表に後の年号を出すなら**薄いグレーで予告のみ、説明しない**）
* 1画面の要素は最大6個。全図解でデザインを統一

## 6．音の設計

### 止めてから戻す

最も強い感情はここで生まれる。

> 中止でBGMを完全停止。環境音も落とす。日付8枚は無音。8月23日のスイッチ音でBGM再開。

### 時刻付きで指定する

**悪い**：重要な場面ではBGMを下げる
**良い**：

| 時間 | 操作 |
| -- | -- |
| 0:43〜0:53 | ハンコの場面。BGMを一段下げ、スタンプ音を1回だけ立てる。押した直後に戻す |
| 1:04〜1:12 | 大字幕。ほぼ無音まで下げ、表示後0.5秒静止してから戻す |

### 効果音

* 「使用可」と「禁止・非推奨」を列挙
* **回数の上限を書く**（コミカル効果音は前半で合計2〜3か所まで、など）。連発は品を落とす
* 効果音はナレーションより前に出さない
* 生活音は「大きすぎると高齢視聴者が驚く」ため自然な音量で

### 終わり方

ナレーション終了後もBGMを3〜5秒残し、自然にフェードアウト。**突然の暗転・無音終了は禁止。**

## 7．事実・表現上の注意

**「正しい扱い」と「禁止表現」を必ずセット。** 禁止だけでは編集者が動けない。

```
| 正しい扱い | 「多くの地域では」「場所も期間も、地域によって違いました」と幅を持たせる |
| 禁止表現 | 「全国どこでも朝6時半だった」「毎日必ず開催されていた」「子どもは全員参加していた」 |
```

必ず扱う型（テーマに合わせて具体化）：

1. **地域差・年代差**（全国一律と断定しない）
2. **条件の違う数字**（因果でつながない、延べ人数と実人数を区別）
3. **資料が割れている事項**（どちらにも正解マークを付けない）
4. **人物の描き方**（一人の英雄物語にしない）
5. **政治・皇室・戦争に触れる事項**（解釈を加えない、過度に荘厳にも批判的にもしない）
6. **昔と今の比較**（美化も否定もしない、仕組みの違いとして扱う）
7. **出典が必要な事項**（画面表示の位置まで指定）

## 8．サムネイル

* **最優先要素を1つ決める。** 小さく表示されたとき最初に目に入るもの
* 主要要素3〜4個以内。文字は合計25字以内が目安
* **タイトル全文を入れない。** タイトルと組み合わせて一つの疑問を作る
* **視認順を書く**（例：赤いハンコ → 眠そうな子ども → メイン文言 → 補助文言）
* 極端な驚き顔・泣き顔を使わない。感情は「眠い」「戸惑い」など具体的に指定する
* 全体を暗いセピアにしない
* **スマートフォンの一覧表示サイズ（幅約320px相当）に縮小して読めるか**を確認手順として書く

## 9．Shorts

* **結論をすべて説明せず、欠落を残す。** 最後の答えはぼかして見せる（「図解を一瞬だけ、ぼかして見せる。答えを読ませない」）
* **ただし誤解を与える切り取りはしない。** 長尺で付けている留保はShortsでも付ける。45秒で留保を付けきれない話題は、**Shortsで扱わない**と明記する
* 冒頭フック → 共感 → 意外性 → 長尺への誘導、の4役を必ず置く
* 長尺と同じ映像・同じナレーションの言い回しを使うと、視聴者が続けて見たとき違和感がない
* 横長素材を単純に切り抜かない。9:16専用レイアウトを作る
* 右側UI・下部表示に重要文字を重ねない
* 公開後、関連動画機能で長尺を設定する旨を書く

## 10．チェックリスト

**汎用チェックだけにしない。今回の動画固有の人物・数字・結論を入れる。**

**悪い**：□ 事実が正しい／□ 権利に問題がない
**良い**：
> □ 1925年／1927年／1928年9月／1930年7月21日 約130人／1932年 延べ2,593万人／1945年8月15日・8月23日／1951年5月 がすべて正しい
> □ 面高巡査が後ろ姿またはシルエットで、顔が作られていない
> □ 図解3の中央に矢印がなく、赤い注意書きが最初から最後まで出ている
> □ 7:58〜8:15でBGMが完全に止まり、8:15のラジオのスイッチ音で再開している

区分：構成／画面／字幕／音響／事実／権利／納品形式

## 11．最終合格基準

**矢印で感情の順序を示す。**

> 懐かしい → 自分も適当に体操していた → ハンコの時だけ元気だった → でも、なぜ毎朝だったのか → 御即位記念の事業だったのか → 今の第一は3代目だったのか → ハンコのためだけではなかった → 自分の地域では何をもらったか話したい

そのあと**200〜300字**で、この動画がどんな体験を提供するのかをまとめる。
機能の列挙ではなく、視聴者の中で何が変わるかを書く。

> 見終えたとき、視聴者の記憶の中の赤い丸は、出席の印から、夏休みの朝そのものの記録へと意味を変えています。

## 12．編集者への語りかけ

指示書は命令書ではない。**工夫を歓迎する意思を、直接語りかける文で書く。**

> 良い工夫を見つけたら、遠慮なく入れてください。「本書に書いていないから入れなかった」という判断はしないでください。企画意図と事実を変えない範囲であれば、演出の追加は歓迎します。

> 仕様書を消化することではなく、最後まで見たくなる一本の作品を作ることを最優先としてください。

同時に、**相談すべきタイミングを限定する**と編集者が動きやすい。

> 権利上どうしても使用できない必須素材がある場合、AI再現が安定しない場合、正式ナレーションと尺が大きく合わない場合は、完成まで進める前にご相談ください。細かな演出判断ごとのご確認は不要です。

## 13．よくある失敗

| 失敗 | 直し方 |
| -- | -- |
| 見本のテーマの構成・原稿を流用する | 見本から借りるのは粒度だけ。問いから作り直す |
| タイトル未指定のまま資料からテーマを推測して着手 | タイトルは一度確認する。ここだけは止まってよい |
| 冒頭で歴史や定義から始める | 1秒目は物・音・時刻。歴史は視聴者が思い出した後 |
| 画面設計が「イメージ映像を表示」 | ①②③と何を映すか、どこを大きく、どうつなぐかまで書く |
| 章の時刻が飛んでいる／合計が合わない | シーンの秒数を足し上げて検算する |
| ナレーション全文が一部の章にしかない | 見出しを数える |
| 数字を矢印や増加グラフで結ぶ | 分離して並べ、中央を空けたまま注意書きを常時表示 |
| 禁止事項だけ並べる | 「正しい扱い」を必ず対にする |
| チェックリストが汎用文だけ | 今回の数字・人物・結論を書き込む |
| 不明な情報を埋めてしまう | 【要確認】【URL未取得】。埋めない勇気 |
| 迷った経緯を文書に書く | 内部検討は外注者向け文書に混ぜない |
