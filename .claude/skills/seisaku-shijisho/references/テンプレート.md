# 制作指示書 テンプレート（節の並びと必須項目）

見出しの並びはこの順。各節の「必ず入れる」を落とさない。
テーマによって不要な節があれば省いてよいが、省いた理由を末尾の未確定事項へ書く。

---

## 表題

```
# 【暫定版 or 完成版】YouTube「〔チャンネル名〕」第〔N〕本目
# 〔正式タイトル全文〕
## 外注編集者向け 制作・編集指示書（長尺／Shorts／サムネイル）
```

冒頭に1〜2行、この文書の位置づけ。【暫定版】なら末尾に未確定事項がある旨を書く。

---

## 発注条件

表形式。**値が分からない項目は `〔　　〕` の空欄のまま残す。**

必ず入れる行：正式タイトル／納品物／長尺 想定尺／Shorts 想定尺／長尺 形式／Shorts 形式／サムネイル形式／納品期限／報酬／無償修正回数／連絡手段／支給素材

続けて **納品ファイル名**の表（確認版・修正版・完成版）。

---

## 支給素材の区分

図解、BGM、写真、小道具について、次のいずれかを必ず明記。

* **【発注者支給】** ファイル名を書く
* **【編集者制作】** 簡単な仕様（色、含める要素、含めない要素）
* **【支給有無 要確認】** 区分が分からない場合

固定BGM、追加BGM、効果音、図解、小道具、実写素材、AI再現、ナレーション音声、ロゴ・終了画面素材を網羅する。

---

## 1．この動画の設計方針

必ず入れる：

* **中心となる問い**（太字で1〜2文）
* 冒頭から歴史説明・一般論を始めない旨の注意
* **視聴前の認識 → 視聴後の認識**（表）
* **視聴後に残す感情**（3項目程度）
* **全体の流れ**（9段：冒頭の記憶・違和感／視聴者が知っている日常／タイトルの問い／意外な背景・歴史／タイトルへの答え／現在との違い・社会的な意味／視聴者自身の記憶へ戻す／コメントしたくなる質問一つ／終了画面）
* **笑いの方向**（「分かる、そうだった」の笑い。人を小馬鹿にしない）
* **ツッコミ字幕 候補10個程度**（表：No／字幕／想定シーン）＋ 使用ルール（集中させる章、表示時間、1画面1本）

---

## 2．時間設計

必ず入れる：

* **章構成の表**（章／時間（開始〜終了）／タイトル／尺）＋ 合計行
* 空白・重複がない旨の確認文
* **画面変化の目安**（表）＋「目安である」旨
* **冒頭60秒 詳細設計**（表：時間／尺／画面／音）＋ 1秒目から本編である旨

---

## 3．制作判断の優先順位

3区分で明記。

* **絶対に固定する部分**：事実、数字、年号、固有名詞、結論、権利、BGMクレジット、最後の質問、出典表示
* **編集者の裁量を認める部分**：カットの長さ、ズーム、パン、画面転換、テロップの装飾、追加BGMの選定、効果音の位置、ツッコミ字幕
  → **完成度が上がる工夫は歓迎する旨を、編集者へ直接語りかける文で書く**
* **禁止する部分**：事実の改変、権利侵害、実在人物のAI顔、過剰な煽り字幕、昔を美化して現在を否定すること

---

## 4．字幕設計

必ず入れる：通常字幕は1画面2行以内／ナレーション全文を常時字幕にしない／文字を小さくしすぎない／書体・色・表示時間／強調色の使い分け／**大字幕5〜8個の表**（No／時間／大字幕／演出）

---

## 5．音声・BGM設計

必ず入れる：

* ナレーター・速度（表）
* **固有名詞の読み**（本文に出てくるものだけ）
* 間を入れる場所
* 固定BGM（ファイル名・提供・URL・使用箇所・概要欄クレジット）
* 追加BGMの方向性（章ごと）／確認できないものは【未確定】
* 使用できる効果音／禁止・非推奨
* **BGMを止める場面、戻す場面**（時刻付きの表）

---

## 6．章別制作設計

各章について、この順で。

```
# 第○章　章タイトル
## 時間
## この章の役割
## 視聴者へ起こす感情（2〜4項目）
## BGM
## シーン設計
| 時間 | シーン | 画面設計 | ナレーション・字幕 | 音・つなぎ |
## ナレーション全文
```

* シーン表の「ナレーション・字幕」は要点の抜粋でよい。ただし**章末のナレーション全文が正式原稿**である旨を、節の冒頭に一度書く
* **ナレーション全文は1文ずつ改行。** VOICEVOXへそのまま貼り付けられる状態にする
* 画面設計は「適切な素材を表示」で終わらせない（品質基準.md を参照）

---

## 7．図解設計

4〜7個。先に**共通ルール**（順に出す／長時間静止させない／条件の違う数字を矢印で結ばない／後の章の結論を先出ししない／配色・要素数の上限）を書く。

各図解は表で：

| 項目 | 内容 |
| -- | -- |
| 使用シーン | シーン番号と時刻 |
| テーマ | |
| 目的 | |
| 画面構成 | 図形の配置が情報の関係を表すように |
| 表示順 | 何秒後に何を点灯させるか |
| 注記 | 途中に実写を挟む等 |
| **禁止表現** | この図解で特にやってはいけないこと |

---

## 8．サムネイル設計

必ず入れる：目的／画面構成（左・右・背景）／**最優先要素**／メイン文字・補助文字／視認順／タイトルとの関係／禁止事項／スマートフォン一覧表示での確認

* **正式タイトル全文を入れない**
* 主要要素は3〜4個以内
* タイトルと同じ内容の繰り返しにせず、**組み合わせて一つの疑問を作る**

---

## 9．誘導用Shorts 設計

45〜60秒で1本。仕様（尺・比率・解像度・ナレーター・BGM）を先に書く。

| 時間 | 役割 | 映像 | ナレーション・字幕 |

役割は最低4つ：**冒頭フック／共感／意外性／長尺への誘導**

* 結論をすべて説明せず、長尺で答えを知りたくなる**欠落**を残す
* ただし誤解を与える切り取りはしない（長尺で付けている留保は、Shortsでも付ける。付けきれない話題はShortsで扱わない）
* 縦画面の注意（UI・下部表示に重要文字を重ねない）
* **Shorts ナレーション全文**を末尾に置く

---

## 10．素材・AI再現

必ず入れる：使用できる素材（優先順）／使用禁止素材／クレジット／**AI再現が必要な場面**（表）／AI再現で避けるもの／**時代考証**（章ごとに、その時代に無いもの）／「再現イメージ」表示のルール

---

## 11．事実・表現上の注意

**今回のテーマ固有の注意を5項目以上。** 各項目を表で、**「正しい扱い」と「禁止表現」をセット**で書く。

```
## 注意〔N〕　〔見出し〕
| | 内容 |
| -- | -- |
| 正しい扱い | |
| 禁止表現 | |
```

---

## 12．納品前チェックリスト

区分：**構成／画面／字幕／音響／事実／権利／納品形式**

* すべて「□」で始める
* **今回の動画固有の人物、数字、結論を含める**（汎用チェックだけにしない）

---

## 13．最終合格基準

* **視聴者の感情がどの順で動けば合格か**を矢印でつないで示す
* **この動画がどんな体験を提供するのかを200〜300字**でまとめる

---

## 14．出典・参考資料

* 本編で画面表示が必要な出典（該当箇所／出典／画面表示／URL）
* 制作の基準として参照した資料（資料名／版・日付／役割）
* **資料間で内容が異なった箇所と、その処理**

---

## 15．未確定・要確認事項

【暫定版】の場合は必須。3つに分ける。

1. **着手前に確定が必要**
2. **納品前までに確定が必要**
3. **資料で確認できず、意図的に扱わなかった事項**（＝創作しなかったもの。本編へ追加しないよう明記）

---

## 16．外注編集者様へのご案内

そのまま送付できる案内文。納品物、尺、ナレーション原稿の場所、この動画で最も大切なこと、裁量の範囲、相談すべきタイミング。
