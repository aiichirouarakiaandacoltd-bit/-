# 長尺の尺と視聴維持の調査(2026-11-27・荒木指示「ドラマ化・日本称賛・海外の反応を加えると尺が長くなる。競合と比べてどれくらいが維持率が高いか」)

担当: 企画係(分析のみ。制作・コミットはしていない)

---

## 0. 結論(荒木さん向け・先に結論)

1. **推奨尺: 目安12〜14分、上限15分、下限10分。** 今の「8〜12分」から上限を3分延ばし、その分をドラマ化(山場・次の疑問)・海外の反応(出典付き)・日本称賛(事実で言える敬意)に使う。**20分を超える尺(昼ドラ型3チャンネルの標準)は採らない。** 確度は **中〜低**(理由は2と3)。
2. **競合の視聴維持率は公開されておらず、分からない(未確認)。** そこで公開されている数字(尺・再生数・登録者数・コメント数)を物差しにした。皇室系65チャンネル・直近の長尺1,796本では、**尺と再生数の関係はほぼゼロ**(順位相関 ρ=0.06)。同じチャンネルの中で比べても中央値 ρ=0.00(延ばして伸びた所が28、落ちた所が28)。**尺を延ばしても再生数は増えも減りもしない**というのが、外から測れる範囲の事実。
3. **20分超が伸びて見えるのは、尺のせいではない。** 20分超のチャンネルは、皇族方の対立・揶揄の題名(ρ=0.69)と毎日公開(ρ=0.27)とがそろっている。**題名が好意・事実型のチャンネルで数字が出ている所は、ほぼ全部8〜13分**(世界が見た雅子さま11分・日本一新8.6分・令和の輝き11.3分)。「海外の反応」型の中でも、同じチャンネルで**長い回ほど再生が少ない**傾向(14チャンネル中9つで負の相関。皇室の夢は15分未満の回の中央値3.5万回、15〜20分の回は1.0万回)。好意・事実型の中央の1位「衝撃のJAPAN【海外の反応】」は9〜18分(中央11.8分)。
4. **長さを足すなら、足した分を見てもらえる場合だけ意味がある。** YouTube 公式は「理想の長さは無い」とし、おすすめは総再生時間と満足度アンケート(5段階で4〜5の視聴時間)で判断すると公表している。12分→14分にしても、見てもらえる割合が下がれば平均視聴時間は変わらない。だから**上限15分で始めて、自分のチャンネルの実測(G7)で決める**。
5. **試し方(G7):** 尺だけを変えた2組(A=10〜12分/B=13〜15分)を交互に3本ずつ出し、公開7日後の「平均視聴時間」「平均再生率」「30秒後の維持(イントロ)」「章ごとの落ち込み」「総再生時間」「直近中央値に対する再生倍率」で比べる。B の平均視聴時間が A の1.15倍以上、かつ平均再生率の低下が5ポイント以内なら B を標準にする(判定基準は当方の提案・**要確認**)。
6. **延ばしても維持率を落とさない作り(要点):** 冒頭30秒で主役の場面と疑問 → 答えは4割までに出す → 答えの直後に「次の疑問」を置き、海外の反応・日本称賛を**後半の山場(全体の6〜8割の位置)**に置く → 章の見出しは疑問の形 → 60〜90秒ごとに新しい事実か人物 → 締めは1分以内。詳細は第5章。

**要確認(判断に迷った点)**
- 制作ルール第3章では成果物は「内部学習教材専用で外部に公開しない」。視聴維持率の実測(G7)は**実際に公開して視聴者がいることが前提**。公開の範囲(限定公開や社内視聴では維持率の比較にならない)を荒木さんに確認したい。
- 第5章「横型の構成 10〜30秒 この動画で分かること」と第5-3章3「『この動画で分かること』の箇条は使わない」が並んでいる。本書では「1文で言う」(5-3章)に合わせた。
- G7の道具は今 CTR の記録(`bin/kabu run ctr`)だけ。平均視聴時間・平均再生率を記録する項目の追加が要る。

## 5. 推奨と根拠

### 5-1. 推奨尺: 目安12〜14分・上限15分・下限10分(確度 中〜低)
| 根拠 | 中身 | 確度 |
|---|---|---|

### 5-2. 試し方(G7・分析係)
1. **前提の確認(要確認):** 公開の範囲。実際の視聴者がいないと維持率は比べられない。
2. **組み方:** 題材の型(A型 行事×一場面×疑問)と主役の人物をそろえ、A=10〜12分/B=13〜15分 を交互に3本ずつ(計6本)。台本の段階で尺を決め、引き延ばし・削りすぎはしない(第5-2章2)。YouTube の「テストと比較」は表紙・題名の試験で、**尺は同じ動画では試せない**ため、交互に出して比べる。
3. **測るもの(公開7日後・YouTube Studio の数字):** 平均視聴時間/平均再生率/イントロ(30秒後も見ている割合)/主要な瞬間(トップモーメントとディップの位置)/総再生時間/インプレッションのクリック率/直近中央値に対する7日後の再生倍率(第5-3章9)/コメント数。vidIQ は残高が戻れば(12/21 に150)チャンネル分析で補う。
4. **判定(当方の提案・要確認):** B の平均視聴時間が A の1.15倍以上で、平均再生率の低下が5ポイント以内、7日後の再生倍率が A を下回らない → B(13〜15分)を標準に。満たさない → A(10〜12分)に戻す。
5. **章ごとの点検:** 海外の反応・日本称賛の章の前後で落ち込み(ディップ)が大きければ、その章を短くするか位置を前に出す。トップモーメントが後半なら前へ。
6. **記録:** 今の `bin/kabu run ctr` には維持率の項目が無い。平均視聴時間・平均再生率・イントロを `data/` に残す項目の追加が要る(要確認)。
7. 6本で差がはっきりしなければ、もう3本ずつ追加する。
