# 宮内庁の写真・映像の利用条件(2026-11-23 原文確認)

## 原文の要点
1. サイト・SNS(YouTube含む)のコンテンツは、特記がない限り宮内庁に著作権があり、公共データ利用規約(PDL1.0)を適用。利用時は出典(例「出典：宮内庁YouTube(URL)」)、加工時は加工した旨を記載。
2. ただし「第三者の権利の対象となるもの」の例として、**皇室の方々のおことば・記者会見・ご講演など皇室の方々が著作・発言されたもの**と、**皇室の方々が写っている画像・映像**が明記されている。これらは権利処理済の明示がない限り、**利用者の責任で権利者の許諾を得る**必要がある。著作権法上の引用など許諾不要の場合もある。
3. 宮内庁が著作権を持つ写真・映像を出版物・テレビ・資料などに使う場合は事前許可(電話→申請書→審査約10日。使用予定日の1か月前まで)。対象は原則「報道・教育・広報など公共性、もしくはそれに準ずる」もの。
4. 許可しない場合:皇室の品位・信用を損なうおそれ/特定の個人・団体の宣伝/**営利目的の販売品や広告、個人的な目的**。さらに「**個人がSNSを始めとするインターネット上のページに当庁の著作物を転載して外部に向け発信し、不特定多数の人が閲覧できる状態にすることも『個人的な利用』を逸脱しており、これも認めておりません**」。
5. 再使用(二次使用)も都度申請。複製・改ざん・譲渡は不可。

- おことば・会見の文言は「皇室の方々が著作・発言されたもの」=第三者の権利の対象。短い引用は著作権法の引用の要件(主従関係・必要性・明瞭な区別・出所の明示)を満たせば許諾不要の場合があるが、要件の判断は専門家に確認。
- 公開前に弁護士(著作権・肖像権)へ確認が必要。
