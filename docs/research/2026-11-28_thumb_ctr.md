# CTRが高い皇室系の表紙 調査(長尺・ショート)2026-11-28

## 0. 結論
1. **伸びている表紙に、額縁・金の飾り・AIの背景は1枚もない。** どれも「本物の写真か映像の一場面」の上に「極太の大きな文字」を載せただけ。前回の当方の表紙が「AIっぽい」と言われた原因はここにある。
2. **写真は「ご近影(室内でかしこまった写真)」ではなく「動きのある一場面」。** 相手がいて、振り向く・笑う・手を取る・歩くなど、何かが起きている瞬間。伸びた長尺24本のうち、かしこまった肖像だけの表紙は人物史の型(後述 型2)を除いてほぼない。
3. **文字は画面の4〜5割を占める。** 2〜3行、1行10〜15字、縁取りの太いゴシックか明朝。色は白・黄が基本、要所だけ赤や水色。
4. **ただし、伸びなかった動画も同じ見た目をしている(sheets の long_low・short_low)。** 見た目の型は「最低条件」で、伸びを決めるのは「どの一場面を選んだか」と「続きが気になる一言」。確度:中。
5. **上位の多くは作った台詞・矢印・?!・赤丸を使っている。** 当チャンネルの決まりでは使えないので、そこは外して型だけ取り入れる。

## 1. 調べ方と限界
- 他チャンネルのCTRは非公開。代わりに**伸び倍率=その動画の再生数÷そのチャンネルの直近の中央値**で「よくクリックされた表紙」を推定した。題材の強さも混ざるので、CTRそのものではない(確度:中)。
- 長尺: 11/24取得の皇室系競合の長尺4,300本から、中央値5,000回以上のチャンネル・30万回以上・1チャンネル3本まで。
- ショート: 11/28に公開ページから皇室系ショート15チャンネル(直近48本+人気順30本)を取得。20万回以上・1チャンネル3本まで。ショートの表紙は、多くが動画の1コマ目そのもの。
- vidIQは残高0のため不使用。
- 一覧画像: docs/research/thumb_ctr_20261128/ 。動画の一覧(倍率・再生数・URL)は同じ場所の data.md。

## 4. 当チャンネルへの示唆
1. **飾りをやめ、写真と文字だけで作る。** AIは使わない(使うとしても表紙には不要)。
2. **表紙の写真を「行事・ご公務の一場面」にする。** お誕生日の題材でも、その年のご公務で相手と笑顔を交わされた場面などを選ぶ(第9章「お誕生日・新年のご近影ばかりにしない」とも合う)。
3. **長尺は型2(明朝・顔を並べる)と型1(場面+3段)の2系統でABテスト**。ショートは型A(帯は濃紺)と型B。
4. **見た目より「一場面の選び方」と「続きが気になる一言」に時間を使う。**
