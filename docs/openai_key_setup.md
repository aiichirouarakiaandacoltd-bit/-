# OpenAI の鍵(APIキー)の登録のしかた

2026-11-27 確認。

## 結論
**まだつながっていません。** 環境「youtube-shorts-pipeline」に、OpenAI の鍵が1つも登録されていない状態です。
(確かめ方:api.openai.com に小さな問い合わせを送ったところ、通信の門番に「この行き先は許可されていない」と断られました。環境の設定を読むと、「Network secrets」の欄が空でした。)

鍵を作っただけ、または別の環境(たとえば「Default」)に登録した場合に、この状態になります。
下の手順で、**「youtube-shorts-pipeline」の環境に**登録してください。

## 手順(画面ごと)

### 1. OpenAI の鍵を用意する(OpenAI のサイト)
1. パソコンのブラウザで platform.openai.com を開き、ログインします。
2. 左のメニュー(または右上の歯車)から **「API keys」** を開きます。
3. **「Create new secret key」** を押し、名前に「皇室物語 表紙」などを入れて作ります。
4. 表示された `sk-` で始まる長い文字列を**コピー**します(この画面を閉じると二度と見られません)。
5. 画像生成にはお支払い設定が必要です。左のメニューの **「Billing」** で、カードの登録と残高(数ドル分)があるかを確かめてください。

※ 鍵の文字列は、チャットには貼らないでください。

### 2. Claude の環境に登録する(claude.ai/code)
1. ブラウザで claude.ai/code を開き、このプロジェクトのチャット(セッション)を開きます。
2. 画面の**いちばん上(題名の並び)**にある、**環境の名前**の表示(「youtube-shorts-pipeline」など)を押します。
3. 出てきた一覧で、**「youtube-shorts-pipeline」の横の編集(「Edit」または鉛筆の印)**を押します。
   ※「Default」ではなく、必ず「youtube-shorts-pipeline」を選んでください。
4. 設定の画面を下へ進み、**「Network secrets」**(古い画面では「API credentials」)の欄を探します。
5. **追加(「Add」や「+」)**を押し、次のように入れます。
   - ホスト(Host):`api.openai.com`(前に https:// は付けない)
   - 種類:**Bearer**(「Authorization: Bearer」)
   - 値(Value / Secret):1-4 でコピーした `sk-…` の鍵を貼り付け
   - 名前(表示名):「OpenAI」など分かりやすいもの
6. **保存(「Save」)**を押します。
7. 一覧に「api.openai.com」の行が出ていれば登録完了です。

### 3. もう一度ためす
- 登録が済んだら、このチャットで「OpenAI につながったか確かめて、表紙の作り直しを続けて」と送ってください。
- 登録から反映まで1分ほどかかることがあります。
