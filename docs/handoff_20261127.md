- 荒木さんの評価: Python で作った見本(projects/PLAN-20261127-DRAMA/thumb_sample/・thumb_abtest/)も、Canva で作った版(thumb_canva_hq/long_A_canva.png、編集URL https://www.canva.com/d/6ah4Srbkv7AwRtY)も「ダサい」。

- 使い方の線引き(荒木さんにも説明済み): **AI で作るのは背景・額縁・金の飾り・光の演出・文字の装飾だけ。皇族方の顔や姿は宮内庁の本物の写真を切り抜いて使う(AI で作らない・顔を加工しない)。** 実在の建物(皇居・宮殿)をそれらしく描かせない。

- 表紙の決まり(production_rules.md 第5章・第9章に記載): 文字はお顔・頭に掛けない(体は可)/菊の御紋は使わない/赤は使わない(帯はラズベリー #D92B5E 前後)/怒り・汗マーク・矢印・赤丸・作った台詞・皇族方の対立や比較の構図は使わない/「」の中は宮内庁の原文の一字一句/目線が下がった写真は使わない/写真の撮影情報と出典を小さく入れる/黒の帯は荒木さんが嫌う。
- 依頼の中身: **ABテスト用に長尺の表紙3枚(1280×720)とショートのカバー1枚(1080×1920)。** 題材の見本は「雅子さま 63歳のお誕生日(12/9)・令和7年のご感想(戦後80年)」。「」は「あと20年で100年もの月日が」(これは終戦から100年の意味。原文は projects/PLAN-20261127-DRAMA/raw/empress2025.txt)。写真は assets/KB-20261124-01/A060〜A066(宮内庁 令和7年のご近影。A065 は下を向いているので表紙には不可)。
