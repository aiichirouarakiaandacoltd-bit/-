# 荒木さん向け制作ガイド：昭和平成 日本再発見

---

## 毎回の作業フロー（5ステップ）

荒木さんが毎回やること：

```
1. テーマ入力（1分）
2. 生成ファイル確認・修正（30〜60分）
3. 素材収集・AI画像生成（1〜3時間）
4. 動画編集（3〜6時間）
5. 最終確認・投稿（30分）
```

---

## Step 1：テーマ入力（自動生成）

```bash
# セットアップ（初回のみ）
pip install -r requirements.txt
export ANTHROPIC_API_KEY="your-api-key-here"

# 動画生成コマンド
python -m generator.main generate \
  --theme "銭湯が消えた理由" \
  --series "消えた日本シリーズ"
```

生成完了後、`videos/[id]/` に17ファイルが作成される。

---

## Step 2：確認すべきファイルの優先順位

### 必ず確認（高優先）
| ファイル | 確認ポイント |
|---------|-----------|
| `01_plan/plan.md` | 方向性が正しいか。核となる問いが適切か |
| `04_script/script.md` | 事実確認。不確かな数字・情報を修正 |
| `10_rights_check/rights_check.md` | 使用予定素材のリスクを把握 |

### 確認してから使う（中優先）
| ファイル | 確認ポイント |
|---------|-----------|
| `02_titles/titles.md` | 10案から1〜2本を選ぶ |
| `03_thumbnail_text/thumbnail_text.md` | サムネイル文言を選ぶ |
| `05_narration/narration.md` | 読みやすいか。自分の言葉に直したい部分はあるか |

### そのまま使える（低優先確認）
| ファイル | 用途 |
|---------|-----|
| `06_subtitles/subtitles.srt` | 編集ソフトに読み込む |
| `08_ai_image_prompts/prompts.md` | そのままMidjourneyに入力 |
| `14_youtube_description/description.md` | BGMクレジット記入後にコピペ |

---

## Step 3：AI画像生成手順（Midjourney）

1. `08_ai_image_prompts/prompts.md` を開く
2. シーンごとのプロンプトをコピー
3. Discord の Midjourneyで `/imagine` コマンドを入力
4. 生成された画像を保存（`videos/[id]/assets/ai_images/`）
5. **必ず確認**：実在する人物・商標が映り込んでいないか

## 絶対にやってはいけないこと

| NG行動 | 理由 |
|--------|-----|
| 実際の昭和平成の楽曲をBGMに使う | JASRACが管理。収益化停止・削除のリスク |
| テレビ映像・芸能人写真を使う | 著作権・肖像権侵害 |
| AI生成画像に「再現イメージ」を付けない | 事実との混同を招く |
| 不確かな数字を断定的に語る | 信頼性の低下 |
| 単なる懐古で終わる台本 | チャンネルコンセプトとの不一致 |

## よくある質問

**Q: 台本の数字が間違っている場合は？**  
A: `04_script/script.md` を直接編集してOK。Claudeが生成した数字は必ず一次資料（厚生労働省・国立公文書館等）で確認すること。

**Q: BGMはどれを選べばいい？**  
A: DOVA-SYNDROMEと甘茶の音楽工房が最も使いやすい。「ノスタルジー」「昭和」「ゆったり」で検索。必ず「YouTube収益化可」を確認する。

**Q: ナレーションは自分で録音する？AIで作る？**  
A: どちらでもOK。自分の声を使う場合は感情が伝わりやすい。AIの場合はCoeFont、VOICEVOX、ElevenLabsが選択肢。将来的には固定のナレーターキャラクターを作ることも検討。

**Q: 動画の投稿頻度は？**  
A: 最初の10本は週1〜2本を目標。無理しない。量より質を優先。
